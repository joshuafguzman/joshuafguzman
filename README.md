### 🚀 Featured Repositories

#### 📂 [grc-automation-suite](https://github.com/joshuafguzman/grc-automation-suite)
> *Enterprise-ready Python automation toolkit for cloud compliance auditing and CMMC/NIST POA&M generation.*
- **`cloud_grc_auditor.py`:** Multi-region AWS scanner auditing IAM console MFA, S3 default encryption, and unrestricted `0.0.0.0/0` ingress on management ports (SSH/RDP).
- **`nessus_to_poam.py`:** Transforms raw Tenable/Nessus vulnerability exports into standardized DoD / CMMC POA&M registers with automated SLA scheduling.
- **`evidence_integrity_verifier.py`:** Cryptographic SHA-256 evidence integrity and tamper-detection utility (*NIST AU-9 / CMMC 3.3.1*).
- **`ir_notification_timeline.py`:** Calculates statutory incident response notification clocks (*DoD DFARS 72h, MD MPIPA 45d, SEC 4-day Form 8-K*).
- **`vendor_risk_scorer.py`:** Automated third-party software and SaaS supply chain risk scoring engine (*NIST SP 800-161*).

#### 📂 [Nested-Groups](https://github.com/joshuafguzman/Nested-Groups)
> *Recursive Parent Group Finder: Locates all parent groups for nested Active Directory groups using a starts-with filter (`gr*`).*

#### 📂 [Users-Unique-Groups](https://github.com/joshuafguzman/Users-Unique-Groups)
> *PowerShell RBAC utility to compare two users and identify unique security group memberships for access audits.*

#### 📂 [Python-csv-xlsx-sql-inserts-converter](https://github.com/joshuafguzman/Python-csv-xlsx-sql-inserts-converter)
> *Python data pipeline script to convert CSV or XLSX evidence logs directly into SQL insert statements.*
